Calendar address and event pill fixes — original investigation

Address cause and resolution
api/calendar.js independently concatenated venue/address/city/state/ZIP even
when address already contained the locality. All calendar providers now share
api/_calendar-location.js. It retains complete addresses, appends only missing
structured components, preserves country text, groups state/ZIP, and avoids
substring matches such as UT inside Utah Street. Maps/directions keep their
existing formatter and coordinates; their behavior was not changed.

Pill cause and resolution
The native app's App.tsx getAvailableEventDisplayPills/resolveEventDisplayPills
treat display_pills as selected keys. category/subcategory/more/custom map to
category_name/subcategory_name/sub_subcategory_name/custom_category_label.
Null selects smart defaults; an explicit empty list hides classification pills.
The old website incorrectly printed the parent classifications plus raw keys.
api/_event-pills.js now resolves keys and appends the native-style price label.
It preserves selected custom label casing and does not infer free pricing from
empty ticket types or null summaries. The native application was read-only.
